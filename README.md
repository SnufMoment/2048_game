# 2048

Компьютерная игра «2048» для одного игрока на Python и Pygame. Нужно сдвигать числовые плитки на поле 4×4 и объединять одинаковые, чтобы собрать плитку 2048.

Проект выполнен командой **«Большой Банан»** в рамках практической работы № 1 по дисциплине «Тестирование и верификация программного обеспечения» (РТУ МИРЭА).

## Установка и запуск

1. Установите Python 3 с [python.org](https://www.python.org/downloads/). На Windows при установке отметьте пункт **Add Python to PATH**.

2. Установите Pygame:

   ```bash
   pip install pygame
   ```

3. Перейдите в папку с проектом и запустите игру:

   ```bash
   python main.py
   ```

   На Linux и macOS может понадобиться команда `python3 main.py`.

После запуска откроется окно игры размером 500×620 пикселей.

> **Важно.** Размещайте проект по пути без кириллицы и пробелов, например `C:\games\2048`. Так вы избежите проблем с путями в некоторых окружениях.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ | Сдвинуть плитки вверх |
| ↓ | Сдвинуть плитки вниз |
| ← | Сдвинуть плитки влево |
| → | Сдвинуть плитки вправо |
| R | Начать игру заново |
| Esc | Выйти из игры |

Закрыть игру можно и крестиком окна.

## Правила игры

- Игра начинается с двух плиток на поле 4×4.
- Каждым ходом все плитки сдвигаются в выбранную сторону до упора.
- Две соседние плитки с одинаковым значением при столкновении объединяются в одну с удвоенным значением. За один ход плитка объединяется не больше одного раза.
- За каждое объединение к счёту прибавляется значение новой плитки.
- После каждого хода, который что-то изменил на поле, на случайной свободной клетке появляется новая плитка: 2 (с вероятностью 90 %) или 4 (с вероятностью 10 %).
- **Победа**: на поле появилась плитка 2048. Выводится сообщение «Вы победили!».
- **Поражение**: свободных клеток нет и никакие две соседние плитки не совпадают. Выводится сообщение «Игра окончена».

После победы или поражения нажмите **R**, чтобы начать заново.

## Архитектура

Игровая логика и отрисовка разделены: состояние игры меняет только `Game2048`, а `Renderer` его только читает.

```
Пользователь ──(клавиши)──► main() ──(команда хода)──► Game2048
                              │                           │
                              │                    (состояние поля)
                              │                           ▼
                              └──(запрос отрисовки)──► Renderer ──► окно Pygame
```

| Компонент | Назначение |
|---|---|
| `Game2048` | Хранит поле, счёт и флаги победы и поражения. Выполняет ходы (`move`, `compress`, `merge`), создаёт новые плитки (`spawn_tile`), проверяет окончание игры (`check_game_over`) |
| `Renderer` | Рисует поле, плитки, счёт, подсказку по управлению и сообщения о победе и поражении |
| `main()` | Инициализирует Pygame, обрабатывает нажатия клавиш и перерисовывает кадр 60 раз в секунду |
| Константы | Размер поля и клеток, отступы, палитра плиток, частота кадров |

Ход в любую сторону сводится к ходу влево: поле поворачивается по часовой стрелке нужное число раз, сдвигается влево и поворачивается обратно.
