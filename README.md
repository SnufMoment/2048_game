Техниеское задание на разработку игры «2048»
   1. Введение
Разрабатываемый программный продукт представляет собой компьютерную игру «2048», предназначенную для одного пользователя. Игра реализуется на языке программирования Python с использованием библиотеки Pygame. Основной областью применения программы является развлекательная и учебная сфера. Продукт может использоваться для отдыха, а также в учебных целях для демонстрации разработки простого игрового приложения.
   2. Основания для разработки
Основанием для разработки программного продукта является выполнение практической работы по дисциплине, связанной с разработкой и тестированием программного обеспечения. В качестве исходных материалов используются требования к практической работе и методические указания по её выполнению. При разработке используются официальная документация языка Python и библиотека Pygame: официальная документация Python и официальная документация Pygame
   3. Назначение разработки
Назначением разработки является создание простой компьютерной игры «2048», позволяющей пользователю перемещать числовые плитки по игровому полю и объединять плитки с одинаковыми значениями. Программа должна обеспечивать игровой процесс, подсчёт набранных очков, определение победы и окончания игры, а также возможность перезапуска и завершения работы программы.
   4. Требования к программе
Программа должна обеспечивать создание игрового поля размером 4×4 клетки и размещение на нём начальных плиток. Пользователь должен иметь возможность перемещать плитки вверх, вниз, влево и вправо с помощью клавиш со стрелками. При перемещении две одинаковые соседние плитки должны объединяться в одну с удвоенным значением. После успешного хода на свободной клетке должна появляться новая плитка. За объединение плиток должны начисляться очки.
Программа должна определять достижение плитки со значением 2048 и состояние окончания игры при отсутствии возможных ходов. Пользователь должен иметь возможность начать игру заново с помощью клавиши R и завершить работу программы с помощью клавиши Esc.
Программа должна сохранять работоспособность при выполнении стандартных действий пользователя. При возникновении ошибки программа не должна приводить к потере управления системой или другим критическим последствиям. После перезапуска состояние игрового поля и счёт должны быть сброшены.
Для эксплуатации программы необходим персональный компьютер с установленным Python 3 и библиотекой Pygame. Для работы игры подключение к сети Интернет не требуется. Программа должна запускаться локально.
Программа должна быть совместима с операционными системами, на которых поддерживается Python 3 и библиотека Pygame. Дополнительное взаимодействие с внешними программными системами не требуется.
   5. Требования к интерфейсу
Интерфейс программы должен содержать игровое поле размером 4×4 клетки, числовые плитки, отображение текущего счёта и краткую подсказку по управлению. Для различных значений плиток должны использоваться различные цвета.
При достижении значения 2048 на игровом поле должно отображаться сообщение «Вы победили!». При отсутствии возможных ходов должно отображаться сообщение «Игра окончена». Клавиша R должна использоваться для перезапуска игры, а клавиша Esc — для выхода из программы. Элементы интерфейса должны быть расположены таким образом, чтобы пользователь мог легко воспринимать игровое поле, счёт и сообщения.
   6. Критерии приёмки
Программа считается соответствующей требованиям технического задания, если она запускается без критических ошибок, отображает игровое поле 4×4 и позволяет выполнять основные игровые действия. Все четыре направления перемещения должны работать корректно, одинаковые плитки должны объединяться, после успешного хода должна появляться новая плитка, а счёт должен изменяться при объединении плиток.
Кроме того, программа должна корректно определять победу при получении значения 2048, окончание игры при отсутствии возможных ходов, перезапуск игры и завершение работы. Успешным результатом приёмки считается прохождение не менее 90% подготовленных тестовых случаев.
7. Требования к документации
В состав документации программного продукта должны входить техническое задание, краткое руководство пользователя и описание архитектуры программы. Руководство пользователя должно содержать информацию о запуске игры, правилах игры и управлении. Описание архитектуры должно содержать информацию об основных компонентах программы и схему их взаимодействия.
   8. Порядок контроля и приёмки
Контроль программы проводится методом ручного функционального тестирования. В процессе проверки выполняется запуск программы и проверяется корректность отображения игрового поля, перемещения и объединения плиток, появления новых плиток и начисления очков. Также проверяются условия победы и окончания игры, перезапуск программы клавишей R и завершение работы клавишей Esc.
Для приёмки используются заранее подготовленные тестовые случаи, описывающие основные функции программы. Результаты тестирования фиксируются в виде пройденных и непройденных тестов. Программа принимается при успешном выполнении не менее 90% тестовых случаев и отсутствии критических ошибок, препятствующих запуску или основному игровому процессу.
   9. Этапы и сроки разработки
Разработка программного продукта выполняется последовательно. На первом этапе создаётся игровое поле и реализуется начальное состояние игры. На втором этапе реализуется перемещение и объединение плиток. На третьем этапе добавляются подсчёт очков, создание новых плиток и проверка окончания игры. На четвёртом этапе разрабатывается графический интерфейс и добавляются сообщения о победе и проигрыше. На заключительном этапе проводится тестирование программы и исправление обнаруженных ошибок.
Общий срок выполнения разработки составляет 3 дня: разработка игровой логики — 1 день, разработка интерфейса — 1 дня, тестирование и исправление ошибок — 1 дня.
